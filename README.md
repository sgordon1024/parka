# Parka

A made-up weather app that tells you what to wear. It was built with Claude, in plain
HTML, CSS, and JavaScript, as a demo for a designers' talk. Nothing here is a real product.

- Live site: https://sgordon1024.github.io/parka/
- Screens: Today, Week, and Places, all running on the live forecast
- Design system: Baseline. This project's whole brand lives in `baseline/tokens/seed.css`.

Weather data by [Open-Meteo.com](https://open-meteo.com/) (CC BY 4.0). Icons by
[Lucide](https://lucide.dev/) (ISC).
